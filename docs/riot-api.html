Riot API usage

Today In-House (투데이 내전) · Developer Portal app 913403 · updated 2026-11-26

Today In-House does not use the Riot Web API or any API key. It only talks to services that run locally on the player's own PC: the League Client API (LCU), the Live Client Data API and the Replay API.

League Client API — read

  • /lol-summoner/v1/current-summoner, /lol-summoner/v2/summoners/puuid/{puuid} — who is logged in, names of room members
  • /lol-gameflow/v1/gameflow-phase, /lol-gameflow/v1/session — lobby / game state, queue and map
  • /lol-champ-select/v1/session — picked champions (shown after the game only)
  • /lol-end-of-game/v1/eog-stats-block — end-of-game result and stats
  • /lol-match-history/v1/games/{gameId}, /lol-match-history/v1/game-timelines/{gameId}, /lol-match-history/v1/products/lol/current-summoner/matches — recovering a result if the end-of-game screen was missed
  • /lol-ranked/v1/current-ranked-stats, /lol-ranked/v1/ranked-stats/{puuid} — official rank, only to balance Summoner's Rift in-house teams (not shown as our own ranking)
  • /lol-game-queues/v1/custom, /lol-lobby/v2/lobby, /lol-lobby/v2/lobby/invitations, /lol-lobby/v2/received-invitations — custom lobby state
  • /lol-replays/v1/configuration, /lol-replays/v1/metadata/{gameId}, /lol-replays/v1/rofls/path — replay availability
  • /lol-game-data/assets/... — champion / item / augment icons
  • /entitlements/v1/token — our server checks its signature against Riot's public keys so each player can only write their own data (never stored or logged)

League Client API — actions

Only on the room host's click, or by settings each player can turn off.

  • POST /lol-lobby/v2/lobby — create / update the custom lobby for the room
  • POST /lol-lobby/v2/lobby/invitations — invite room members
  • POST /lol-lobby/v2/received-invitations/{id}/accept — accept an invite only from the room host
  • /lol-lobby/v2/lobby/team/{team}, /lol-lobby/v1/lobby/custom/switch-teams — move to the assigned team
  • POST /lol-lobby/v2/lobby/members/{id}/kick — remove a member the host removed from the room
  • /lol-lobby/v2/lobby/matchmaking/search — start / cancel queue for a normal-game party (party leader's click)
  • /lol-replays/v1/metadata/{gameId}/create/..., /lol-replays/v1/rofls/{gameId}/download/graceful, /lol-replays/v1/rofls/{gameId}/watch — open the finished game's replay on the host's PC

Live Client Data API (port 2999, read only)

/liveclientdata/eventdata, /liveclientdata/playerlist, /liveclientdata/activeplayer, /liveclientdata/gamestats — collected during the player's own game and used only after the game to pick the highlight moment (kill times, own health). Nothing is shown during the game.

Replay API (port 2999)

/replay/playback, /replay/render, /replay/sequence, /replay/recording — after the game the host's app opens the replay and records one short highlight clip. This needs EnableReplayApi=1 in game.cfg.
