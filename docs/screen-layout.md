# 화면 좌표 (실측)

롤 화면 위에 무언가를 올릴 때(마커·배지·정보 띠·하이라이트 등) 쓰는 위치 기록이다. 모든 값은 실제 스크린샷을 픽셀 단위로 스캔해 얻었고, 계산·추측 값과 다르면 이 문서가 맞다.

- 측정 환경(2026-11-01): 모니터 1대 3440×1440 · 배율 100%(DPI 96) · 롤 클라 1280×720(`riotclient/zoom-scale` 1.0) · 패치 16.21
- 다시 잴 때: 클라 창 사각형 = `FindWindow(null, "League of Legends")` + `DwmGetWindowAttribute(9)`(보이는 실제 경계) · 화면 캡처 = PowerShell `CopyFromScreen`(SetProcessDPIAware 먼저) · 픽셀 스캔 = ffmpeg로 rgb24 원본을 뽑아 node로 밝기·색 구간 찾기

## 1. 롤 클라이언트(1280×720 기준)

클라는 1280×720 화면을 통째로 늘린다(창이 크면 모든 좌표 × `창 너비 / 1280`). 아래 좌표는 창 왼쪽 위 기준이다.

### 공통
| 요소 | 좌표 |
|---|---|
| 맨 위 메뉴줄 | y 0~82 (아래 경계 y 82) |
| 「파티 구성/플레이」 버튼 | x 30~190 · y 24~60 |
| 친구 목록 사이드바 | x 1056~1280 (전체 높이 · 펼침/접힘과 무관) |
| 오른쪽 아래 아이콘 줄 | y 688~718 · x 1060~1280 |

## 2. 게임 화면(인게임 · 3440×1440 실측 → 높이 비율)

롤 게임 화면 UI는 **화면 높이**를 기준으로 커진다. 가운데 요소는 화면 가운데 기준, 가장자리 요소는 그 가장자리 기준으로 쓴다(H = 화면 높이, cx = 화면 가운데 x).

### 증강 선택 카드(아수라장)
| 요소 | 3440×1440 | 비율 |
|---|---|---|
| 카드 3장(테두리) | x 1017~1442 · 1507~1932 · 1997~2422 | 카드 가운데 = cx, cx ± 0.340H · 너비 0.296H |
| 카드 위쪽 끝 | y 257 | 0.178H |
| **카드 이름 줄** | y 579~604 | **0.40~0.42H** (OCR 띠 = 0.26~0.54H) |
| 카드 아래쪽 끝 | y ≈ 955 | ≈ 0.66H |
| 블리츠 등 다른 앱 표시(카드 아래 Tier) | y ≈ 894~989 | 이름 줄을 가리지 않음 |
| 리롤 버튼 | y ≈ 989~1049 | ≈ 0.69~0.73H |
| 「레벨」 증강 열기 버튼 | x ≈ 1585~1855 · y ≈ 1100~1187 | 가운데 아래 |

## 3. 리플레이 녹화 화면(팟지)

| 항목 | 값 |
|---|---|
| 녹화 창 | 1920×1080 창 모드(녹화 동안만 · 끝나면 원래대로) |
| 카메라 | 주인공 따라가기 `cameraMode top` · 기울기 56° · 기본 시야 50 → v0.1.80부터 60(원거리 68) |
| 주인공 위치 | 시점이 비스듬해 화면 **아래쪽**(대략 0.6~0.9 높이)에 놓임 → 아래를 잘라내면 안 됨 |
| 녹화 시작 | 롤은 startTime을 안 기다리고 재생과 동시에 찍음 → 영상 0초 = 녹화 끝 − 영상 길이로 실측 |
