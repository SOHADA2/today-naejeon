# 화면 좌표 (실측)

롤 화면 위에 무언가를 올릴 때(마커·배지·정보 띠·하이라이트 등) 쓰는 위치 기록이다. 모든 값은 실제 스크린샷을 픽셀 단위로 스캔해 얻었고, 계산·추측 값과 다르면 이 문서가 맞다.

- 측정 환경(2026-11-01): 모니터 1대 3440×1440 · 배율 100%(DPI 96) · 롤 클라 1280×720(`riotclient/zoom-scale` 1.0) · 패치 16.21
- 다시 잴 때: 클라 창 사각형 = `FindWindow(null, "League of Legends")` + `DwmGetWindowAttribute(9)`(보이는 실제 경계) · 화면 캡처 = PowerShell `CopyFromScreen`(SetProcessDPIAware 먼저) · 픽셀 스캔 = ffmpeg로 rgb24 원본을 뽑아 node로 밝기·색 구간 찾기
